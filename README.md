# Figura — Unofficial 26.3 Port

An **unofficial** port of [Figura](https://github.com/FiguraMC/Figura) to **Minecraft 26.3 (Fabric)**.

> This is NOT an official Figura release. All credit for Figura goes to the
> FiguraMC team (skyrina, lumelia, UnlikePaladin, omoflop and contributors).
> Please do **not** report issues with this port to the Figura developers —
> use this project's issue tracker instead.
> Official Figura: https://modrinth.com/mod/figura

## What changed
- Ported to Minecraft 26.3 / Fabric Loader 0.19.5+ / Java 25
- Rendering rewritten for the new 26.x render pipeline and retained-mode GUI
- Fabric-only (no Forge/NeoForge builds)

## Known limitations
- GeckoLib armor compatibility is disabled
- Some features (HUD parts, portraits, custom nameplates) may still have rendering issues

## Requirements
- Fabric Loader 0.19.5 or newer
- Fabric API is bundled (only the modules Figura needs)
